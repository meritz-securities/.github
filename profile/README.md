## 공개한 저장소

| 저장소 | 내용 |
|---|---|
| [`open-api`](https://github.com/meritz-securities/open-api) | Python 호출 예제와 REST·WebSocket 명세 |
| [`open-api-mcp`](https://github.com/meritz-securities/open-api-mcp) | AI 클라이언트용 MCP 서버 |
| [`open-api-codegen-mcp`](https://github.com/meritz-securities/open-api-codegen-mcp) | API 호출 코드 생성 MCP |
| [`open-api-studio`](https://github.com/meritz-securities/open-api-studio) | CLI와 에이전트 스킬 |

현재는 공개 저장소와 개발 자료를 먼저 확인하실 수 있습니다. 서비스 이용 시점과 API 신청 방법은 정식 오픈 안내에서 별도로 알려드리겠습니다.

## 안내

- 고객용 저장소의 `main`과 Release만 공개합니다.
- 개발 작업과 내부 이력은 비공개 저장소에서 관리합니다.
- 정식 서비스 오픈 전까지 API 신청과 운영 이용 안내는 준비 중입니다.

**곧 찾아뵙겠습니다.**
