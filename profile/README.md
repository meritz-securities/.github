# 메리츠증권 Open API

**정식 공개를 준비하고 있습니다. 곧 찾아뵙겠습니다.**

현재 저장소는 보안 점검과 공개 준비를 위해 잠시 비공개로 운영합니다.

</div>

---

## 준비 중인 저장소

| 저장소 | 내용 |
|---|---|
| `open-api` | Python 호출 예제와 REST·WebSocket 명세 |
| `open-api-mcp` | AI 클라이언트용 MCP 서버 |
| `open-api-codegen-mcp` | API 호출 코드 생성 MCP |
| `open-api-studio` | CLI와 에이전트 스킬 |

보안 점검과 공개 준비가 끝나면 저장소와 정식 서비스 이용 방법을 다시 안내드리겠습니다.

**곧 찾아뵙겠습니다.**
